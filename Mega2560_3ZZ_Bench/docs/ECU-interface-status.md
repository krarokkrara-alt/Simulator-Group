# วงจร interface ECU — ยังไม่อนุมัติให้ต่อใช้งาน

ผู้ใช้ต้องการทั้งหน้าจอควบคุมและวงจรแปลงสัญญาณ สำหรับทดสอบบนโต๊ะ เครื่องยนต์ยืนยันล่าสุดเป็น 3ZZ-FE กล่อง 89661-02860 และมี PD60 จำลองหัวฉีด ข้อมูลนี้แทนการระบุเครื่อง 1ZZ-FE ในช่วงต้น ยังต้องยืนยันผังขาและรูปคลื่นจากเอกสารตรงรุ่น

## หลักฐานภาพอุปกรณ์จากผู้ใช้

ภาพฉลากยืนยัน Toyota 89661-02860, Denso MA 175200-7031, 12V, 3ZZ-FE, M/T ภาพหน้าปลั๊กเป็นการมองเข้าขั้ว ECU แต่ยังไม่มีผังเลขขาที่ตรวจสอบตรงกับกล่องนี้ จึงยังไม่กำหนดขาสายจากตำแหน่งในภาพ

อุปกรณ์โหลดเป็น PD60+ มีฉลาก Fuel injector and ignition simulator, DC IN 12–24V, DC Out, Ignition Module (+), Ignition coils (-), Gasoline Injector (-), Diesel Injector (+/-) และขั้ว OBD CAN-H/CAN-L/LIN/K ตามข้อความหน้ากล่อง ภาพไม่แสดงขั้วชื่อ CKP/CMP/NE/G จึงยังไม่มีหลักฐานว่า PD60+ สร้างหรือแปลงสัญญาณรอบได้ ต้องตรวจคู่มือก่อนใช้คุณสมบัติที่ไม่ระบุ ห้ามใช้ขั้วโหลดหรือ DC Out แทนขั้วสัญญาณรอบ

ค่า 12–24V เป็นข้อความอินพุตของ PD60+ ไม่ใช่พิกัดของ ECU ซึ่งฉลากระบุ 12V ภาพถ่ายอย่างเดียวไม่ยืนยันว่าการต่อสายปัจจุบันถูกต้องหรือระดับแรงดันปลอดภัย

## ผลทดสอบ Mega

Mega ผ่านการ upload และรับส่ง Serial บน COM4 สัญญาณที่โปรแกรมสร้างขณะนี้มีเฉพาะ CKP ลอจิก 36-2 ที่ D11; D12 ยังไม่สร้าง CAM ไม่มีผลวัดรูปคลื่นที่ขาจริง

## โครงสร้างที่ต้องพัฒนาต่อ

PC control panel → USB → Mega → วงจรสร้าง/แปลงรูปคลื่น CKP และ CMP ที่มี output-enable ปิดโดยปริยาย → อินพุตเซนเซอร์ของ ECU

PD60 เป็นโหลดหัวฉีดแยกจากเส้นทางสร้างสัญญาณ เว้นแต่คู่มือของรุ่นนั้นยืนยันว่ามีฟังก์ชันสร้าง NE/G ด้วย ห้ามนำเอาต์พุตหัวฉีด ECU ต่อ Mega โดยตรง

## ข้อมูลที่ต้องตรวจให้ตรงก่อนออกวงจรและเลือกค่าอุปกรณ์

1. ได้ภาพฉลากและหน้าปลั๊กแล้ว ยืนยัน M/T ยังต้องมีรุ่นรถ/ปี และ EWD ที่ตรงรุ่นเพื่อยืนยันทิศมองและเลขขา
2. ได้ภาพรุ่นและขั้ว PD60+ แล้ว ยังต้องตรวจคู่มือและวงจร interface ที่มีอยู่แล้ว
3. รูปคลื่น CKP/CMP ของรุ่นจริง: polarity, amplitude ที่ cranking/idle, ตำแหน่ง CAM เทียบ missing gap, impedance และการอ้างอิง NE-
4. แหล่งจ่าย ECU พร้อมฟิวส์/จำกัดกระแส และแผน grounding/isolation ของ USB กับโต๊ะทดสอบ

ต้องเลือก driver ตามชนิดอินพุตจริง วงจร open-collector สำหรับอินพุต Hall ไม่ถือว่าใช้แทนวงจรจำลอง VR ได้โดยอัตโนมัติ ห้ามต่อ D11/D12 เข้าขา ECU โดยตรง และห้ามถือว่า NE- เป็นกราวด์ทั่วไปโดยไม่มีผังยืนยัน

## เกณฑ์ก่อนระบุว่าพร้อมทดสอบ ECU

- ยืนยัน pinout และแหล่งจ่ายตามกล่องจริง
- วัด CKP/CMP ผ่าน driver ด้วย oscilloscope ทั้งระดับแรงดัน จังหวะ และช่วง RPM
- ทดสอบ reset, USB disconnect, โปรแกรมปิด และเอาต์พุตหยุดโดยค่าเริ่มต้น
- ต่อ ECU แบบจำกัดกระแส ตรวจ RPM และ cam/crank sync ด้วยเครื่องสแกนก่อนต่อโหลดจริง
