# ชุดสัญญาณ 3ZZ-FE และวงจรที่ต้องเพิ่ม

สถานะ: ซอฟต์แวร์สำหรับทดสอบสัญญาณบนโต๊ะ ยังไม่ใช่ชุดต่อ ECU พร้อมใช้ ห้ามต่อขา Mega เข้า ECU โดยตรง

## ช่องในรุ่นนี้

| สัญญาณ | Mega | รูปแบบ | สถานะ |
|---|---|---|---|
| CKP/NE | D7 | ลอจิกทดสอบ 36 ช่อง เว้น 2 ช่อง | ต้อง driver จำลอง pickup/VR ก่อน ECU |
| CAM/G2 | D2 | พัลส์ทดสอบ 1 ครั้งต่อ 720 องศา ตั้ง phase/width ได้ | START เปิดคู่ CKP; phase ยังไม่ยืนยัน |
| TPS/VTA | D5 | PWM test ค่าเป้าหมายเฉลี่ย 0–5000mV | ไม่ใช่ DAC ต้อง filter/buffer และวัดจริง |
| MAP | D6 | PWM test ทั่วไป | ไม่ยืนยันว่า ECU รุ่นนี้ใช้ MAP; ไม่ใช่ช่อง VG |
| MAF/VG | D8 | PWM test ค่าเป้าหมายเฉลี่ย 0–5000mV | ต้อง filter/buffer และอ้างอิง EVG ตามผัง |
| THW น้ำหล่อเย็น | ไม่มีเอาต์พุต Mega | จำลองความต้านทานแทน thermistor | ต้องวงจรภายนอก |
| THA อากาศเข้า | ไม่มีเอาต์พุต Mega | จำลองความต้านทานแทน thermistor | ต้องวงจรภายนอก |

ไม่ได้อ้างว่าสร้าง SPD, O2, knock, IGF หรือสัญญาณคันเร่งคู่ได้ครบ คันเร่ง ACCP MAIN/SUB ในใบงานเป็นความสามารถกล่องจำลองทั่วไป ไม่ยืนยันว่าต้องใช้กับกล่องคันเร่งสายรุ่นนี้

## TPS แบบปรับด้วยมือ (ไม่ต้องใช้ DAC จาก Mega)

เมื่อยืนยันขา VC, E2, VTA ตรง ECU แล้ว สามารถใช้ potentiometer linear 10kΩ เป็นตัวแบ่งแรงดันจาก VC ของ ECU ไป E2 และใช้ wiper ผ่านตัวต้านทานอนุกรม 1kΩ ไป VTA เป็นแนวทางทดสอบ ต้องต่อ/ตรวจด้วยมิเตอร์ขณะปิดโหลดจริง ปรับค่าเริ่มต้นใกล้ 0.5V ก่อน และวัดค่าจริงอ้างอิง E2 ไม่ต่อแหล่งจ่าย 5V ของ Mega ขนานกับ VC ค่า 10kΩ/1kΩ เป็นข้อเสนอวงจรสำหรับตรวจสอบ ยังไม่มีผลทดลองกับกล่องนี้

คู่มือ RM821E ระบุ VTA ขณะปิดลิ้น 0.3–1.0V และเปิดสุด 3.2–4.9V ค่านี้เป็นช่วงตรวจวินิจฉัย ไม่ใช่สมการแปลงเปอร์เซ็นต์ TPS ที่คาลิเบรตแล้ว

## TPS/MAF ที่ควบคุมผ่านคอมพิวเตอร์

PWM ของ Mega เป็นสวิตช์ 0/5V ไม่ใช่แรงดัน DC ตามตัวเลขใน UI เอาต์พุต 8 บิตมีขั้นประมาณ 19.6mV เมื่อ Vcc เท่ากับ 5V จริง และค่าเฉลี่ยขึ้นกับ Vcc จริงด้วย

วงจรทดสอบ filter เบื้องต้นต่อช่อง: ขา PWM → R 10kΩ → จุดวัด; C 10µF จากจุดวัดไป GND Mega (ตรวจขั้วตัวเก็บประจุ) ใช้กับมิเตอร์/oscilloscope เท่านั้น ค่า time constant ประมาณ 0.1s ต้องรออย่างน้อย 0.5s ก่อนอ่านค่า ห้ามนำจุดวัดนี้ต่อ ECU โดยถือว่าพร้อมแล้ว ต้องเพิ่ม buffer, protection, output-enable และแผน reference ground ที่ตรงช่อง VTA/VG รวมทั้งวัด ripple และ startup/reset

สำหรับงาน ECU ใช้ DAC พร้อม driver/reference ที่ออกแบบและตรวจแล้วจะเหมาะกว่า ยังไม่มี DAC ในฮาร์ดแวร์ที่ยืนยัน จึงไม่อ้างว่าปุ่มใน UI เปลี่ยนแรงดัน ECU ได้โดยตรง

## THW/THA

ใช้กล่อง decade resistor หรือ resistor ที่เลือกตามตาราง R–T ของเซนเซอร์จริง ระหว่าง THW–E2 และ THA–E2 ไม่ส่ง PWM เข้าแทน thermistor ไม่กำหนดค่าโอห์มเป็นองศาจากการเดา ไม่แสดงอุณหภูมิจริงใน UI จนมีตารางคาลิเบรตและวงจรปรับความต้านทาน

## คำสั่ง Serial เพิ่มเติม

115200 baud, newline:

```text
STOP
RPM 800
CAM OFF
CAM 0 2
SENSOR TPS 500
SENSOR MAF 1200
SENSOR MAP 1000
CONFIG
START
STATUS
SENSOR OFF
STOP
```

`CAM 0 2` เป็นตัวอย่าง phase ทดสอบ ไม่ใช่ค่าแนะนำเข้า ECU หน่วย phase/width คือครึ่งช่อง CKP (5 องศาเพลาข้อเหวี่ยง) phase 0–143 ครบ 720 องศา width 1–12 ตั้งได้ตอนหยุดเท่านั้น เอาต์พุตหยุดเริ่มต้น แต่ทุก START จะเปิด CMP พร้อม CKP แม้ก่อนหน้าสั่ง CAM OFF; STOP/timeout ปิดทั้งคู่

SENSOR แต่ละช่องต้องส่งซ้ำภายใน 5 วินาทีจึงคง PWM; UI จะส่งซ้ำเฉพาะค่าที่ผู้ใช้สั่งไว้ STOP ปิดทั้งสัญญาณรอบและ sensor PWM โดยไม่เปิดกลับเอง START ไม่กู้ค่า sensor ที่ถูกปิดไปแล้ว
