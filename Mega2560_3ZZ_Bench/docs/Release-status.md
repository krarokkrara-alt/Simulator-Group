# สถานะชุดส่งมอบ

1 พฤศจิกายน 2026 — 3ZZ-FE, ECU 89661-02860 M/T

## ส่งมอบแล้ว

- Mega3ZZ-Control.exe พร้อม Open-Control-Panel.cmd ตัวเปิดหน้าจอ Windows ใช้ .NET Framework และ Windows PowerShell runtime ที่มีในเครื่อง ไม่ต้องใช้ Python
- firmware และสคริปต์ install/upload/test สำหรับ Mega 2560
- หน้าควบคุม RPM, TPS, MAF/VG, MAP test และ CAM test พร้อม STOP และ error log ในหน้าจอ
- คู่มือเริ่มใช้งาน รายการขาสัญญาณ ผลทดสอบ และขอบเขตวงจรที่ยังต้องทำ

## ยืนยันจากการทดสอบ

คอมไพล์ firmware ผ่าน และ upload COM4 สำเร็จ Serial test ผ่านทั้งคำสั่ง sensor/CAM การปฏิเสธค่าผิดช่วง STOP และ timeout

สร้าง EXE ผ่าน เปิดแล้วระบบ computer-use พบหน้าต่างแอปจริง ชื่อ Mega 2560 | 3ZZ-FE Bench Control แต่ยังไม่ได้กดปุ่ม GUI ครบทุกปุ่ม เพราะการอ่านหน้าจอรอบตรวจถูกยกเลิก

## ยังไม่เสร็จสำหรับต่อ ECU

ยังไม่มีวงจรจำลอง pickup/VR ที่ประกอบและวัดแล้ว ไม่มี analog driver TPS/VG ที่วัดแล้ว ไม่ยืนยัน CAM phase จริง ไม่ได้ต่อ ECU/PD60 ทดสอบกับซอฟต์แวร์นี้ และยังไม่มีวงจรปรับความต้านทาน THW/THA

ดังนั้นชุดนี้ใช้เตรียม/ทดสอบ Mega กับ USB และเครื่องวัด ส่วนเครื่องจำลอง ECU พร้อมต่อใช้งานยังไม่สำเร็จ การเปิด EXE หรือ ACK จากบอร์ดไม่ยืนยันความถูกต้องของแรงดันหรือรูปคลื่นที่ ECU จะได้รับ
