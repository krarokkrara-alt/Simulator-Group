# เริ่มใช้ Mega 3ZZ Bench

ชุดนี้พร้อมสำหรับทดสอบบอร์ดกับ USB และเครื่องวัด ไม่ใช่ชุดต่อ ECU โดยตรง

## เปิดโปรแกรม

1. ถอดสาย Mega จาก ECU และ PD60 เหลือ USB และเครื่องวัดเท่านั้น
2. เปิด `Open-Control-Panel.cmd` หรือ `Mega3ZZ-Control.exe`
3. เลือก COM4 แล้ว Connect รอข้อความ STOP confirmed
4. กด Load Toyota CKP+CMP test ตอน STOP รอ ACK แล้ว START เพื่อทดสอบทั้ง CKP D7 และ CMP D2 ที่800RPM (phaseทดสอบยังไม่ยืนยัน) หรือใช้ Apply RPM/CAM แยกเอง
5. แท็บ Sensors ใช้ Apply TPS/MAF/MAP แยกช่อง ค่าที่แสดงเป็น PWM target ยังไม่ใช่แรงดันที่วัดจริง
6. STOP ปิดเอาต์พุตทั้งหมด และ Disconnect เมื่อเลิกใช้

ขณะ RUN สามารถลากแถบ Live RPM หรือปรับช่องตัวเลขด้วยปุ่มขึ้นลง/ล้อเมาส์ได้ หน้าจอส่งค่าล่าสุดอัตโนมัติไม่เกินประมาณ5ครั้งต่อวินาทีและรอ ACK ก่อนส่งค่าถัดไป ไม่ต้อง STOP หรือกด Apply ซ้ำ ตอนหยุดยังใช้ Apply RPM ตามปกติ

CAM เป็นพัลส์ทดสอบตั้ง phase/width ได้เท่านั้น ค่า phase 0 ไม่ใช่เฟสที่ยืนยันของ 3ZZ-FE ห้ามไล่ค่าบน ECU โดยไม่มีข้อมูลอ้างอิง

ถ้าเหมือนไม่มีสัญญาณ: ต้องเห็น RUN และเปิด CMP test แล้ว สั่ง START ครั้งเดียวใน Serial Monitor จะหยุดภายใน5วินาที แต่หน้าจอควบคุมส่งต่ออายุให้เมื่อทำงาน เปิด Diagnostics → Read STATS เพื่อตรวจตัวนับซอฟต์แวร์ (ไม่ใช่การวัด Vpp)

วัด CKP: probe CH1 ที่D7; CMP: CH2 ที่D2; ground clips ที่GND Mega เท่านั้นในชุดทดสอบUSB เลือก DC coupling, input1MΩ/Hi-Z ไม่ใช้ termination50Ω ตั้งโพรบและสโคป10x ให้ตรงกัน ระดับลอจิกเป็น0ถึงVccประมาณ5V แต่ยังไม่รับประกัน5.00Vpp ไม่มีชุดปรับแรงดันจากซอฟต์แวร์

## ขา Mega รุ่นปัจจุบัน

| ขา | หน้าที่ |
|---|---|
| D7 | CKP test |
| D2 | CAM test ปิดเริ่มต้น |
| D5 | TPS test PWM |
| D6 | MAP test PWM ทั่วไป |
| D8 | MAF/VG test PWM |
| GND | อ้างอิงเครื่องวัดฝั่ง Mega |

ห้ามตีความตารางนี้ว่าเป็นสายต่อเข้า ECU โดยตรง รายละเอียดวงจรและรายการที่ยังขาดอยู่ใน Sensor-plan-3ZZ.md และ ECU-interface-status.md

## ก่อนต่อ ECU

ต้องมีวงจรจำลอง pickup/VR สำหรับ NE/G, วงจร analog driver สำหรับ TPS/VG, ความต้านทานจำลอง THW/THA, ยืนยัน pinout ตรงกล่อง และวัดรูปคลื่น/เฟสก่อน ยังไม่มีฮาร์ดแวร์เหล่านี้ประกอบและทดสอบในงานนี้ PD60+ ใช้เป็นโหลดตามคู่มือของอุปกรณ์ ไม่ใช่ตัวแปลงขา Mega

อาการพอร์ตไม่พบให้ Refresh ตรวจสาย USB และดู Device Manager; COM3 เป็น Intel AMT ของคอมพิวเตอร์ COM4 ที่เคยทดสอบคือ CH340 หากพอร์ตเปลี่ยนให้เลือกตามเครื่องจริง อย่าเปิด Serial Monitor พร้อมกับหน้าจอควบคุม
