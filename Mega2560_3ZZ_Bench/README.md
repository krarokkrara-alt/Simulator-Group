# 3ZZ-FE / Arduino Mega 2560 — เตรียมทดสอบบนโต๊ะ

ภาพฉลากยืนยัน **3ZZ-FE / M/T / 12V**, กล่อง Toyota **89661-02860**, Denso **175200-7031** อุปกรณ์โหลดเป็น **PD60+** ยังไม่มีข้อมูลวงจรภายในหรือคู่มือของอุปกรณ์นี้

ชื่อโฟลเดอร์ sketch `Mega1ZZBench` คงไว้เพื่อให้สคริปต์เดิมทำงานต่อได้ ชื่อนี้ไม่ใช่การยืนยันโปรไฟล์เครื่องยนต์ เฟิร์มแวร์เป็น CKP/CMP ทดสอบทั่วไป โดย START เปิดทั้งคู่และเฟส CAM ยังไม่ยืนยัน

## สถานะ

โปรเจกต์นี้ยัง **ไม่พร้อมต่อ ECU** รุ่นซอร์สล่าสุดเพิ่ม CAM test แบบตั้งเฟสได้ (START เปิดคู่ CKP อัตโนมัติ) และ PWM test สำหรับ TPS/MAP/MAF โดยยังไม่ยืนยันเฟส CAM หรือวัดแรงดันจริง THW/THA ต้องใช้ความต้านทานภายนอก และ Mega ไม่ใช้เป็นโหลดคอยล์/หัวฉีด ดู [รายการช่องและวงจร](docs/Sensor-plan-3ZZ.md)

ติดตั้ง Arduino CLI 1.5.2-rc.1 และ AVR core 1.8.8 แล้ว รุ่นเพิ่ม sensor/CAM คอมไพล์สำหรับ Mega 2560 ผ่าน: Flash 7,842 bytes, RAM 371 bytes ผู้ใช้ยืนยันเหลือเฉพาะ USB และอัปโหลด COM4 สำเร็จแล้ว ทดสอบ Serial ด้วย scripts/Test-BenchSerial.ps1 ผ่าน รวม sensor/CAM ACK, คำสั่งผิดช่วง, STOP และ timeout จบด้วย STOP / SENSOR OFF / CAM OFF ยังไม่ได้วัดรูปคลื่นหรือทดสอบ ECU

ผลตรวจเฟิร์มแวร์ CKP รุ่นก่อนหน้า 1 พฤศจิกายน 2026: COM3 เป็น Intel Active Management Technology SOL; COM4 เป็น USB-SERIAL CH340 (VID 1A86 / PID 7523) สถานะ Windows OK ผู้ใช้ยืนยันถอด ECU/PD60 และวงจรภายนอก เหลือเฉพาะ USB ก่อนทดสอบ อัปโหลดไป COM4 สำเร็จ (exit code 0) และ Serial 115200 ตอบ STATUS, RPM 800, START, STOP ถูกต้อง ทดสอบไม่ส่ง START ซ้ำแล้วพบ `STOP: START timeout` และ STATUS เป็น STOP บอร์ดถูกสั่ง STOP เมื่อจบทดสอบ

ผลนี้ยืนยันการอัปโหลดและการตอบคำสั่ง แต่ยังไม่ได้วัดรูปคลื่นที่ขา D7/D2 หรือทดสอบกับ ECU ไม่ยืนยันความสมบูรณ์ของขา I/O ทุกขา

ภาพอ้างอิงเป็นกล่องจำลองอีกแบบ มีเมนู VIOS 1NZ-FE และหมายเลข DIP ของอุปกรณ์นั้น ไม่ใช่ผังขา Arduino และไม่ใช้แทนผัง ECU 89661-02860

## ติดตั้งและทดสอบเมื่อเปิด PowerShell ได้

### หน้าจอควบคุม Windows

เปิด `Open-Control-Panel.cmd` ในโฟลเดอร์โปรเจกต์ เลือก COM4 → Connect → รอ STOP confirmed → Apply RPM → START ปุ่ม STOP หยุดสัญญาณ หน้าจอส่ง START ซ้ำขณะผู้ใช้เปิดการทำงาน และส่ง STOP ตอน Disconnect/ปิดหน้าจอ มี log แสดงสถานะและ error ไม่ auto-connect/start เมื่อเปิดแอป ต้องเหลือเฉพาะ USB และเครื่องวัดขณะทดสอบโปรเจกต์รุ่นนี้

แท็บ Sensors มี TPS, MAP (ทั่วไป ยังไม่ยืนยันว่าใช้กับ ECU นี้), MAF/VG ตั้งค่าเป้าหมาย mV และ Apply แยกช่อง UI ต่ออายุ PWM ทุกวินาทีเฉพาะช่องที่สั่งและได้รับ ACK ไม่สั่ง START รอบเครื่องเอง แท็บ CAM เป็นพัลส์ทดสอบ 1 ครั้ง/720 องศา ปรับ phase/width ได้ตอน STOP ต้องใช้เฟิร์มแวร์รุ่นใหม่ ไม่ใช้ค่าทดสอบเป็นค่าเฟสจริงของ ECU

สร้าง `Mega3ZZ-Control.exe` สำหรับเปิดหน้าจอโดยไม่ต้องใช้หน้าต่างคำสั่งแล้ว ต้องเก็บ EXE คู่กับโฟลเดอร์ scripts เปิด EXE และตรวจพบหน้าต่างชื่อ Mega 2560 | 3ZZ-FE Bench Control แล้ว แต่การอ่านหน้าจอรอบตรวจถูกยกเลิก จึงยังไม่ได้ยืนยันการกดปุ่ม GUI จริงครบทุกปุ่ม ผล Serial ที่ผ่านเป็นการทดสอบแยกจากหน้าจอนี้ หากตัวเปิดทำงานผิดพลาดจะแสดงข้อความและบันทึก logs/control-panel-error.log

วงจรแปลงสัญญาณยังไม่มี schematic/BOM พร้อมประกอบ ดู `docs/ECU-interface-status.md` สำหรับข้อมูลที่ต้องยืนยันก่อนออกวงจร

เปิด PowerShell ในโฟลเดอร์โปรเจกต์แล้วรัน:

```powershell
.\scripts\Install-Arduino.ps1
# ดู COM จริงจากผล board list แล้วแทน COM5 ให้ตรงกับบอร์ด
.\scripts\Upload-Bench.ps1 -Port COM5
```

สคริปต์ดาวน์โหลด CLI จาก Arduino และติดตั้ง arduino:avr ผ่าน CLI ไม่มีไลบรารีภายนอกสำหรับ sketch นี้ หากไม่พบพอร์ต ต้องตรวจสาย USB และชนิดชิป USB ก่อนเลือกไดรเวอร์ ไม่ติดตั้งไดรเวอร์ CH340 โดยเดาว่าทุกบอร์ดใช้ชิปนี้

เปิด Serial Monitor 115200 baud เลือก newline ป้อน `STATUS`, `RPM 800`, `START`, `STOP` ขณะเริ่มและรีเซ็ตเอาต์พุตหยุด ต้องส่ง START ซ้ำภายใน 5 วินาทีเพื่อให้ทำงานต่อ เปลี่ยน RPM ระหว่าง RUN ได้ ช่วง 100–6000 RPM โดยไม่รีเซ็ตตำแหน่งพัลส์

ต่อเฉพาะเครื่องวัดลอจิก/ออสซิลโลสโคป: D7 เป็น CKP ทดสอบ 36 ช่อง เว้นสองช่องท้าย; D2 LOW หลัง setup จนกำหนด CAM และ START ใช้ GND ของ Mega เป็นจุดอ้างอิงเครื่องวัดบนโต๊ะ ที่ 800 RPM ต้องวัดคาบหนึ่งรอบประมาณ 75 ms, พัลส์ 34 ลูก/รอบ และช่วง rising edge ข้ามฟันที่หายประมาณ 6.25 ms ตรวจ STOP, timeout และ reset ว่าสัญญาณหยุดจริง

ช่วง reset/bootloader ขา D7/D2 เป็น high impedance จน setup ทำงาน วงจร interface ต้องมี pulldown และ/หรือขา enable ที่ปิดเอาต์พุตโดยปริยาย การ timeout 5 วินาทีตรวจใน main loop ไม่ใช่ hardware watchdog และไม่รับประกันตัดเอาต์พุตเมื่อ MCU ค้าง

## ก่อนพัฒนาเป็นเครื่องทดสอบ ECU

- ต้องมีภาพฉลากกล่องเต็มและผังปลั๊กชัดเจน พร้อมทิศมองขาปลั๊กจากคู่มือรุ่นรถ/ปีจริง ไม่เดาเลขขาจากภาพความละเอียดต่ำ
- ต้องทราบยี่ห้อ/รุ่น PD60 และภาพขั้วต่อ เพื่อแยกโหลดหัวฉีดออกจากวงจรสร้าง NE/G
- ต้องยืนยันรูปคลื่น CKP/CMP จริง โดยเฉพาะจำนวนฟัน CAM, ตำแหน่งเทียบ CKP, polarity และระดับสัญญาณ
- ต้องมีวงจรแปลงสัญญาณสำหรับอินพุต NE/G ของ ECU ตามชนิดเซนเซอร์จริง สัญญาณลอจิก 0–5V จาก Mega ไม่ใช่รูปคลื่นเซนเซอร์ VR โดยอัตโนมัติ ห้ามต่อ D7/D2 เข้าขา NE/G โดยตรง
- ห้ามต่อ 12V, ขาหัวฉีด หรือขาคอยล์เข้าขา Mega; ใช้แหล่งจ่าย ECU จำกัดกระแสพร้อมฟิวส์และโหลดที่เหมาะสม ตามผังวงจรที่ตรวจสอบแล้ว

เอกสาร Arduino: https://docs.arduino.cc/hardware/mega-2560/

ต้องทดสอบรูปคลื่นผ่านวงจรแปลงก่อนต่อ ECU แล้วตรวจด้วยสแกนเนอร์ว่าอ่าน RPM/ซิงก์ได้ จึงเพิ่มเซนเซอร์และตรวจการทำงานของโหลด ยังไม่อ้างว่าไฟล์นี้ทำให้ ECU สั่งหัวฉีดได้
